# 综合分析工作流

## 概述

本 Skill 定义股票综合分析的标准流程，适用于 Analyst（分析师）和 Strategist（策略师）。

## 分析维度

### 1. 技术面分析
- **MA 均线系统**: MA5/MA10/MA20/MA60 多头/空头排列
- **MACD**: DIF/DEA 金叉/死叉、柱状图变化
- **RSI**: 超买(>70)/超卖(<30)/中性区间
- **布林带**: 上轨/中轨/下轨位置、带宽收窄/扩张
- **ATR**: 波动率衡量，用于止损计算
- **支撑/压力位**: 基于近期高低点和均线

### 2. 基本面分析
- **盈利能力**: ROE、净利率、毛利率
- **成长性**: 营收增长率、利润增长率（3年CAGR）
- **财务健康**: 资产负债率、流动比率
- **现金流**: OCF/净利润比率
- **估值**: PE/PB 历史分位、同业对比
- **分红**: 股息率、分红连续性

### 3. 资金面分析
- **主力资金**: 大单净流入/流出
- **散户资金**: 小单流向（通常与主力相反）
- **换手率**: 异常换手率提示

### 4. 新闻/事件面
- **近期催化**: 财报发布、产品发布、政策变化
- **风险事件**: 监管风险、行业利空、管理层变动
- **内幕交易**: 内部人买卖动向（美股适用）

## 评分体系

| 维度 | 权重 | 评分范围 |
|------|------|----------|
| 技术面 | 25% | 1-10 |
| 基本面 | 30% | 1-10 |
| 资金面 | 15% | 1-10 |
| 新闻/事件 | 15% | 1-10 |
| 估值 | 15% | 1-10 |

### 评分标准
- **8-10**: 强烈看多信号
- **6-7**: 偏多/中性
- **4-5**: 偏空/谨慎
- **1-3**: 强烈看空信号

## 多空辩论框架

每只股票必须同时列出看多和看空论据：

### 看多论据来源
- 技术面多头排列、突破关键阻力
- 基本面优秀（高ROE、高增长、低负债）
- 主力资金持续流入
- 正面催化事件（财报超预期、新订单）

### 看空论据来源
- 技术面空头排列、跌破关键支撑
- 基本面恶化（利润下滑、负债上升）
- 主力资金持续流出
- 负面事件（监管风险、行业下行）

## 结构化交易提案格式

```
操作: 买入/持有/卖出/观望
信心度: 高/中/低
入场价: xxx-xxx (说明依据)
止损价: xxx (-x%)
止盈价: xxx (+x%)
风险收益比: 1:x.x
建议仓位: 总资金的 x%

看多论据:
- ...

看空论据:
- ...

综合理由: ...
```

## 注意事项
- 分析基于数据，不做主观臆断
- 如果某维度数据不足，标注"数据不足"并降低该维度权重
- 用户风险偏好影响最终仓位建议（保守型仓位减半）
- 止损价至少基于 ATR×2 或固定比例（取较大值）
